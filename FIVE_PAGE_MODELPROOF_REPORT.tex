\section*{Executive Summary}
In contemporary artificial intelligence engineering, Machine Learning (ML) models govern critical decisions across finance, healthcare diagnostics, and autonomous applications. Despite this reliance, the distribution of serialized models (\texttt{.joblib}, \texttt{.onnx}) faces two fundamental challenges:
\begin{enumerate}[leftmargin=1.5em]
    \item \textbf{Model Tampering \& Poisoning:} Downstream buyers cannot mathematically prove whether downloaded weights were modified, backdoored, or corrupted after training.
    \item \textbf{Opaque Royalties \& Piracy:} AI creators have no trustless, decentralized mechanism to sell model access without surrendering high middleman commissions.
\end{enumerate}

\textbf{ModelProof} solves this through an end-to-end decentralized application (DApp) on Ethereum. By anchoring cryptographic SHA-256 fingerprints to smart contracts, ModelProof delivers an immutable registry where model integrity can be verified on-chain in milliseconds.

\subsection*{Key Contributions of the Project}
\begin{itemize}[leftmargin=1.5em]
    \item \textbf{Dual-Tier Access Protocol:} Differentiates between a budget 30-day API inference license and permanent \textbf{ModelProof Verified\texttrademark} full-weight ownership ($3\times$ price).
    \item \textbf{Direct 98\% / 2\% Escrow Split:} Smart contracts disburse 98\% of incoming ETH directly to model creators and 2\% to platform governance atomically.
    \item \textbf{Emergency Pause Circuit Breaker:} Admin security switch that instantly halts licensing, downloads, and registration during security incidents.
    \item \textbf{Zero-Knowledge Public Verifier:} Browser-based verification portal allowing anyone to cross-check local model files against Ethereum testnet state.
\end{itemize}

\section{Easy-Level Understanding: What is ModelProof?}

\subsection{The Real-World Analogy: Digital Car Title \& DNA Test}
To understand ModelProof without complex technical jargon, compare it to purchasing a car:
\begin{itemize}[leftmargin=1.5em]
    \item \textbf{The Car Title Analogy:} When you buy a vehicle, you inspect the Vehicle Identification Number (VIN) and verify the governmental registration deed. Buying an AI model online today is like buying a used car from an unknown stranger without a registration paper or guarantee that the engine was not secretly swapped.
    \item \textbf{The Digital DNA Test:} Every digital file has a unique mathematical fingerprint (a cryptographic hash). If even one parameter out of 100 million neural network weights is altered, this fingerprint completely changes. ModelProof acts as an unalterable notary that stamps this fingerprint on the blockchain.
\end{itemize}

\subsection{Why Conventional AI Hubs Fall Short}
Existing centralized platforms (HuggingFace, GitHub, AWS Marketplace) suffer from:
\begin{enumerate}[leftmargin=1.5em]
    \item \textbf{Single Points of Failure:} Centralized hosting servers can be compromised, tampered with by bad actors, or experience downtime.
    \item \textbf{Silent Model Drift:} Attackers can re-upload malicious weights under popular names without users noticing minor changes in prediction behavior.
    \item \textbf{High Platform Fees:} Traditional app marketplaces charge 15\% to 30\% commissions and delay creator payouts by weeks.
\end{enumerate}

\subsection{How ModelProof Works in 4 Simple Steps}
\begin{enumerate}[leftmargin=1.5em]
    \item \textbf{1. Train \& Upload:} An AI developer trains a model (e.g., California housing valuation or cancer diagnosis) and uploads it. The backend computes its SHA-256 fingerprint.
    \item \textbf{2. Blockchain Notarization:} Using MetaMask, the creator writes the model's name, version, accuracy, and fingerprint into the Ethereum smart contract.
    \item \textbf{3. Marketplace Purchase:} Buyers browse the catalog. They can buy a \textbf{30-Day API License} for testing or upgrade to \textbf{ModelProof Verified\texttrademark\ Full Ownership} to download the raw weights.
    \item \textbf{4. Instant Tamper Verification:} Anyone holding a model file can drag-and-drop it into the verification portal. ModelProof checks the blockchain: a green check confirms original weights, while any altered file triggers an instant red tamper alert.
\end{enumerate}

\subsection{The Three Roles in the Ecosystem}
\begin{itemize}[leftmargin=1.5em]
    \item \textbf{Creator:} Publishes models, sets prices in ETH, and collects 98\% instant royalties directly into their wallet.
    \item \textbf{Buyer:} Tests models live in the interactive playground, purchases licenses or weights, and verifies authenticity.
    \item \textbf{Admin:} Oversees marketplace health and controls the emergency circuit breaker to protect funds.
\end{itemize}

\section{What is in this Project? Core Features \& Capabilities}

ModelProof unites machine learning inference with decentralized blockchain settlement into a production-grade application.

\subsection{1. Dual-Tier Acquisition System}
Unlike typical marketplaces that force an all-or-nothing purchase, ModelProof introduces two programmatic tiers:
\begin{itemize}[leftmargin=1.5em]
    \item \textbf{Standard 30-Day API License ($1\times$ Base Price):} Grants 30 days of programmatic inference access through the FastAPI backend. Ideal for app developers who do not need to host or manage physical weights.
    \item \textbf{ModelProof Verified\texttrademark\ Full Ownership ($3\times$ Base Price):} Records lifetime ownership on-chain (\texttt{hasModelOwnership = true}), unlocks the raw physical weights download button (\texttt{.joblib}), and awards an official verified creator badge.
\end{itemize}

\subsection{2. Automated Cryptographic Fingerprinting}
During model registration, the system streams file bytes through a SHA-256 algorithm:
\[
\text{File Binary Stream} \xrightarrow{\text{SHA-256}} \text{256-bit Digest} \xrightarrow{\text{On-Chain}} \texttt{bytes32 modelHash}
\]
This hash is permanently anchored in the smart contract. Because the hash is stored on-chain, even if the backend storage is altered, the tampering is detected immediately.

\subsection{3. Smart Contract Escrow \& 98\% / 2\% Revenue Split}
Financial transactions are governed entirely by Solidity smart contracts:
\begin{itemize}[leftmargin=1.5em]
    \item \textbf{98\% Direct Creator Payout:} Transferred directly to the creator's wallet in the same transaction.
    \item \textbf{2\% Platform Protocol Fee:} Routed to the platform treasury for ecosystem maintenance.
    \item \textbf{Zero Middleman Delay:} Settlements execute in seconds without third-party escrow approval.
\end{itemize}

\subsection{4. Emergency Pause Circuit Breaker}
Security is enforced using the OpenZeppelin \texttt{Pausable} pattern:
\begin{itemize}[leftmargin=1.5em]
    \item If anomalous behavior or zero-day exploits occur, the admin executes \texttt{pause()}.
    \item All purchases, licensing, model registrations, and weight downloads are instantly frozen.
    \item The frontend and backend immediately display warning banners and reject operations with HTTP 403.
\end{itemize}

\subsection{5. Interactive AI Playground \& Verification Portal}
\begin{itemize}[leftmargin=1.5em]
    \item \textbf{Live Inference Sandbox:} Users can test pre-loaded models (California Housing, Breast Cancer Classifier, Wine Quality) with real-time input sliders before purchasing.
    \item \textbf{Public Verification Portal:} Drag-and-drop hash verification verifies any model against Sepolia contract state without requiring login or gas fees.
\end{itemize}

\section{Technology Stack \& System Architecture}

\subsection{Simplified Technology Stack Overview}
Rather than using bloated layers, ModelProof utilizes a focused, modern technology stack:

\begin{itemize}[leftmargin=1.5em]
    \item \textbf{Smart Contract Layer (Ethereum / Sepolia):}
    \begin{itemize}[leftmargin=1.2em]
        \item \textbf{Solidity (\texttt{\^{}0.8.20}):} Custom contract logic for model registration, dual-tier licensing, and 98/2 revenue distribution.
        \item \textbf{OpenZeppelin Contracts:} Battle-tested security modules for access control (\texttt{Ownable}) and emergency controls (\texttt{Pausable}).
        \item \textbf{Hardhat Suite:} Local EVM node, automated deployment scripts, and 21 automated unit tests.
    \end{itemize}

    \item \textbf{Backend AI Engine (Python 3.11 / FastAPI):}
    \begin{itemize}[leftmargin=1.2em]
        \item \textbf{FastAPI \& Uvicorn:} Asynchronous, high-throughput REST API server for inference and hashing.
        \item \textbf{Scikit-Learn, XGBoost, Joblib:} ML model training, artifact serialization, and runtime prediction.
        \item \textbf{SQLite / SQLAlchemy:} Fast local caching for catalog metadata and license records.
    \end{itemize}

    \item \textbf{Frontend User Interface (React 18 + Vite):}
    \begin{itemize}[leftmargin=1.2em]
        \item \textbf{React 18 \& TypeScript:} Strongly typed single-page application with reactive state management.
        \item \textbf{Ethers.js (v6):} Lightweight Web3 provider bridging browser components with MetaMask.
        \item \textbf{Lucide-React \& Modern CSS:} Responsive, accessible interface with visual verification badges.
    \end{itemize}

    \item \textbf{Infrastructure \& DevOps:}
    \begin{itemize}[leftmargin=1.2em]
        \item \textbf{MetaMask:} Browser wallet for cryptographic signing and ETH transactions.
        \item \textbf{Render \& Vercel:} Cloud hosting for backend API and frontend client.
    \end{itemize}
\end{itemize}

\subsection{System Architecture Flow}
The platform partitions responsibilities cleanly across three distinct domains:

\begin{center}
\fbox{
\begin{minipage}{0.92\linewidth}
\footnotesize
\textbf{1. Client Layer (React + Ethers.js + MetaMask)} \\
User interacts with UI $\rightarrow$ Signs transactions via MetaMask $\rightarrow$ Direct RPC to Ethereum.
\vspace{0.15cm}

\textbf{2. Off-Chain Intelligence Layer (FastAPI + ML Models)} \\
Handles model uploads $\rightarrow$ Computes SHA-256 fingerprint $\rightarrow$ Serves live sandbox inference.
\vspace{0.15cm}

\textbf{3. On-Chain Settlement Layer (Sepolia Smart Contract)} \\
Stores immutable model hash $\rightarrow$ Splits ETH payment (98\% creator / 2\% admin) $\rightarrow$ Grants ownership.
\end{minipage}
}
\end{center}

\textbf{Gas Optimization Strategy:} Heavy neural network files are \emph{never} stored directly on the blockchain. Only the 32-byte cryptographic digest is anchored on-chain. This provides mathematical tamper resistance while keeping transaction fees near zero.

\section{Operational Workflows, Security Analysis \& Conclusion}

\subsection{Core Operational Workflows}

\subsubsection{Workflow 1: Creator Model Registration}
\begin{enumerate}[leftmargin=1.5em]
    \item The creator uploads a serialized model file (\texttt{.joblib}) via the registration wizard.
    \item The FastAPI backend streams the binary bytes to generate its unique SHA-256 hash.
    \item The creator clicks \textbf{"Publish to Blockchain"}. MetaMask requests an on-chain transaction calling \texttt{registerModel(name, version, hash, priceWei)}.
    \item The Ethereum network confirms the block, permanently notarizing the model.
\end{enumerate}

\subsubsection{Workflow 2: Buyer Licensing \& Ownership Acquisition}
\begin{enumerate}[leftmargin=1.5em]
    \item A buyer selects either the \textbf{30-Day License} ($1\times$) or \textbf{ModelProof Verified\texttrademark} ($3\times$).
    \item The smart contract receives payment, instantly routing 98\% to the creator and 2\% to the admin.
    \item For full ownership, \texttt{hasModelOwnership[id][buyer]} is set to \texttt{true}, unlocking raw model weight downloads.
\end{enumerate}

\subsubsection{Workflow 3: Verification \& Tamper Detection}
\begin{enumerate}[leftmargin=1.5em]
    \item Any user uploads a candidate model file to the public \texttt{/verify} portal.
    \item The portal recalculates the SHA-256 hash and calls \texttt{isModelProofVerified(modelId, hash)}.
    \item If identical, the green verified seal appears; if altered by even one bit, an instant red warning alert is triggered.
\end{enumerate}

\subsection{Security Guarantees}
\begin{itemize}[leftmargin=1.5em]
    \item \textbf{Reentrancy Protection:} All contract disbursements use the Checks-Effects-Interactions pattern.
    \item \textbf{Emergency Fail-Safe:} The admin circuit breaker can freeze all financial operations within seconds.
    \item \textbf{Decoupled Trust:} Private keys remain exclusively within MetaMask and are never shared with the backend.
\end{itemize}

\subsection{Conclusion \& Academic Takeaway}
ModelProof provides a complete, working blueprint for trustless AI distribution. By combining Python-based machine learning inference with Ethereum smart contract provenance, it eliminates middleman fees, prevents silent model poisoning, and offers creators fair, instantaneous compensation.
