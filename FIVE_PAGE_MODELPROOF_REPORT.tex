\section{Easy-Level Understanding: What is ModelProof?}

To understand ModelProof without technical jargon, consider how valuable physical assets like cars or real estate are bought, sold, and protected.

\subsection{The Real-World Analogy: "A Digital Title Deed \& DNA Test for AI"}
\begin{itemize}[leftmargin=1.5em]
    \item \textbf{The Car Title Analogy:} When you purchase a vehicle, you do not just hand over cash and take the keys; you inspect the vehicle identification number (VIN) and verify the governmental registration deed. Before ModelProof, buying an AI model online was like buying a car from an unknown seller with no registration, no title deed, and no guarantee that the engine was not secretly swapped.
    \item \textbf{The Digital DNA Test:} Every file on a computer has a unique mathematical fingerprint (a cryptographic hash). If even a single parameter out of 100 million neural network weights is altered, this fingerprint completely changes. ModelProof acts as the official notary office that registers this fingerprint on an unalterable public ledger (the blockchain).
\end{itemize}

\subsection{Why Existing AI Marketplaces Fail}
Today, data scientists publish models on conventional platforms (e.g., HuggingFace, GitHub, AWS Marketplace). These centralized hubs exhibit significant trust vulnerabilities:
\begin{enumerate}[leftmargin=1.5em,itemsep=2pt]
    \item \textbf{Centralized Single Points of Failure:} A centralized database can be hacked, modified by rogue employees, or seized without user consensus.
    \item \textbf{Silent Model Drift and Backdoor Attacks:} Attackers can re-upload malicious weights under popular names without users noticing subtle prediction changes.
    \item \textbf{Payment Overhead \& High Commission:} Traditional app stores charge 15\% to 30\% platform commissions, delaying creator payouts by weeks.
\end{enumerate}

\subsection{How ModelProof Works in 4 Simple Steps}

\begin{tcolorbox}[colback=badgebg,colframe=accentgreen,title=\textbf{The ModelProof Life Cycle in Four Plain Steps}]
\begin{enumerate}[leftmargin=1.2em,itemsep=3pt]
    \item \textbf{Step 1 --- Build \& Upload:} The AI engineer trains a model (e.g., predicting house prices or credit fraud) and uploads the file to ModelProof. The backend automatically calculates its unique SHA-256 digital fingerprint.
    \item \textbf{Step 2 --- Register on the Blockchain:} The engineer connects a crypto wallet (MetaMask) and notarizes the model on the Ethereum blockchain. The model's name, version, accuracy metric, and fingerprint are permanently written into smart contract storage.
    \item \textbf{Step 3 --- Choose Acquisition Tier:} A buyer browses the marketplace. They can either pay a budget fee in Sepolia ETH for a \textbf{30-Day API Testing License} or pay a 3x premium for the \textbf{ModelProof Verified\texttrademark\ Full Ownership} tier to download the raw weights.
    \item \textbf{Step 4 --- Instant Verification:} Anyone holding an AI weight file can drag-and-drop it into the verification portal. ModelProof checks the blockchain live. If it matches, a green verified seal appears. If a single bit was tampered with, an instant red alert warning is triggered.
\end{enumerate}
\end{tcolorbox}

\subsection{The Three Roles in the Ecosystem}
\begin{itemize}[leftmargin=1.5em]
    \item \textbf{The Creator (Data Scientist):} Registers novel AI algorithms, establishes licensing pricing in ETH, and collects 98\% instant royalties directly into their wallet without waiting for payroll or invoice approvals.
    \item \textbf{The Buyer (Enterprise / Developer):} Discovers verified AI models, tests live predictions in an interactive sandbox playground, and securely purchases licenses or weights.
    \item \textbf{The Administrator (Platform Governance):} Monitors marketplace health and holds an emergency circuit breaker switch to freeze financial transactions if security anomalies occur.
\end{itemize}

\section{Operational Workflows, Security Analysis \& Conclusion}

\subsection{Detailed Operational Workflows}

\subsubsection{Workflow A: Model Registration \& Cryptographic Anchoring}
\begin{enumerate}[leftmargin=1.5em,itemsep=1pt]
    \item The creator prepares a serialized model file (\texttt{model.joblib}) and launches the registration wizard.
    \item The FastAPI backend streams the binary bytes through a SHA-256 hashing pipeline, generating a unique hexadecimal digest.
    \item The creator clicks \textbf{"Publish to Blockchain"}. Ethers.js constructs an on-chain transaction calling \texttt{registerModel(name, version, hash, priceWei)}.
    \item The Ethereum validator network confirms the block; the model is now permanently locked into public state.
\end{enumerate}

\subsubsection{Workflow B: Dual-Tier Purchasing \& Instant Settlement}
\begin{enumerate}[leftmargin=1.5em,itemsep=1pt]
    \item The buyer selects either \textbf{30-Day License} ($1\times$) or \textbf{ModelProof Verified\texttrademark} ($3\times$).
    \item MetaMask prompts the user with the exact ETH value calculated based on current gas fees.
    \item \texttt{ModelProof.sol} executes the financial split: 98\% of the funds are transferred directly to the creator's address; 2\% is transferred to the platform governance address.
    \item If full ownership was selected, the contract toggles \texttt{hasModelOwnership = true}, immediately enabling the physical weight download button.
\end{enumerate}

\subsubsection{Workflow C: Tamper Detection \& Zero-Knowledge Verification}
\begin{enumerate}[leftmargin=1.5em,itemsep=1pt]
    \item Any stakeholder uploads a candidate model file to \texttt{/verify}.
    \item The client computes the file's hash and queries \texttt{isModelProofVerified(modelId, calculatedHash)}.
    \item If the file was altered by even one bit, the hashes mismatch. The UI immediately renders a \textbf{"Tampered / Unverified"} alert, preventing poisoned models from being loaded into production.
\end{enumerate}

\subsection{Security Guarantees \& Circuit Breaker Safeguards}
\begin{itemize}[leftmargin=1.5em,itemsep=2pt]
    \item \textbf{Reentrancy Defense:} All on-chain payment disbursements follow the Checks-Effects-Interactions pattern, preventing recursive drain exploits.
    \item \textbf{Emergency Pause Protocol:} If malicious behavior is detected, the contract owner executes \texttt{setEmergencyPause(true)}. All registration, licensing, and weight download functions immediately revert, protecting user capital.
    \item \textbf{Data Privacy:} Model evaluation datasets remain local; only model metadata and cryptographic commitments are broadcast to the network.
\end{itemize}

\subsection{Academic Conclusion \& Future Scope}
ModelProof demonstrates the successful convergence of machine learning engineering and distributed ledger technology. By offloading computational inference to optimized ASGI Python services while anchoring asset provenance and revenue distribution to Ethereum smart contracts, ModelProof delivers a tamper-proof, fair, and scalable marketplace.

Future iterations of the platform will explore:
\begin{enumerate}[leftmargin=1.5em,itemsep=1pt]
    \item Integrating Layer-2 rollup protocols (e.g., Arbitrum or Optimism) to reduce transaction gas fees to sub-cent levels.
    \item Implementing Zero-Knowledge Machine Learning (zk-SNARKs) to prove model accuracy on test sets without disclosing the test data.
    \item Adding decentralized storage persistence via IPFS and Filecoin for fully distributed weight hosting.
\end{enumerate}
