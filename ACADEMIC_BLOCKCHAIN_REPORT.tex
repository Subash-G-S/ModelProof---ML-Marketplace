\begin{abstract}
The dissemination and commercial distribution of trained Machine Learning (ML) models face severe challenges regarding intellectual property theft, unauthorized model weights alteration, opaque training lineage, and exorbitant 30\% marketplace take-rates. \textbf{ModelProof} resolves these issues by anchoring machine learning model weights directly to the \textbf{Ethereum Sepolia} blockchain through SHA-256 cryptographic hashes and IPFS content identifiers. 

Developed and tested using the \textbf{Hardhat} smart contract development framework, the platform features:
\begin{enumerate}[label=\textbf{\arabic*.}]
    \item \textbf{Autonomous 98/2 Royalty Settlement:} 98\% of licensing revenue routes directly to the ML Creator's MetaMask wallet, while 2\% is retained for protocol governance.
    \item \textbf{Dual-Tier Purchase Paradigm:} A 30-day time-limited DRM license for real-time hosted inference versus a permanent ``ModelProof Verified\texttrademark'' full buyout conferring physical weight downloads (\texttt{.joblib}) and an on-chain ownership certificate.
    \item \textbf{MetaMask Wallet Integration:} Reactive Web3 connection, gas fee estimation, and role-based access for Buyers, Creators, and Platform Administrators.
    \item \textbf{Emergency Circuit Breaker:} Synchronized pause/unpause functionality across Solidity smart contracts, Python FastAPI backend, and React UI to protect against exploits.
\end{enumerate}

\vspace{0.5cm}
\textbf{Keywords:} Ethereum, Smart Contracts, Solidity, Hardhat, MetaMask, Machine Learning Provenance, SHA-256, Decentralized Marketplace.
\end{abstract}

\section{Introduction \& Problem Definition}

\subsection{Background}
Artificial Intelligence and Machine Learning models have become critical enterprise assets. Training state-of-the-art architectures (such as XGBoost, Deep Neural Networks, and Transformers) requires substantial capital, proprietary datasets, and extensive compute resources. However, once serialized into weight artifacts (\texttt{.joblib}, \texttt{.onnx}, \texttt{.pt}), models can be trivially copied, redistributed, or secretly backdoored without credit or payment to original authors.

\subsection{Key Challenges}
\begin{itemize}[leftmargin=1.5em]
    \item \textbf{Integrity Loss \& Model Poisoning:} End-users downloading weights have no cryptographic guarantee that the file matches the published evaluation checkpoints.
    \item \textbf{Predatory Middleman Fees:} Existing software app stores and API aggregators retain up to 30\% commissions on developer earnings.
    \item \textbf{Lack of Provenance Tracking:} Lineage across successive model updates (\texttt{v1.0} $\to$ \texttt{v2.0}) is completely absent in conventional download links.
    \item \textbf{Rigid Licensing Options:} Buyers cannot easily trial a model on live inputs without committing to expensive, opaque commercial contracts.
\end{itemize}

\subsection{Project Objectives}
\begin{enumerate}
    \item Develop and deploy a Solidity smart contract using \textbf{Hardhat} on Ethereum Sepolia.
    \item Implement cryptographic SHA-256 fingerprint commitments to guarantee model integrity.
    \item Automate fair, peer-to-peer 98/2 revenue distribution directly through \textbf{MetaMask}.
    \item Provide a dual-tier purchase model: 30-day time-limited trial vs. permanent ownership buyout.
    \item Provide an offline/online verification portal confirming the official \textbf{ModelProof Verified\texttrademark} standard.
\end{enumerate}

\section{Hardhat Framework Implementation}

\textbf{Hardhat} was chosen as the core Ethereum development environment for compiling, testing, and deploying the \texttt{ModelProof.sol} smart contract.

\subsection{Hardhat Pipeline}
\begin{itemize}[leftmargin=1.5em]
    \item \textbf{Compilation Engine:} Uses \texttt{npx hardhat compile} to target Solidity \texttt{0.8.24} with the EVM optimizer enabled (200 runs).
    \item \textbf{Automated Test Suite:} Written in TypeScript using Mocha and Chai (\texttt{contracts/test/ModelProof.test.ts}), achieving \textbf{100\% pass rate across 21 test cases}.
    \item \textbf{Deployment Script:} Uses \texttt{contracts/scripts/deploy.ts} to deploy artifacts to Ethereum Sepolia and automatically sync contract ABIs to the React frontend.
\end{itemize}

\section{Basic System Breakdown: What is in this Project?}

To understand \textbf{ModelProof} without technical jargon, imagine an online store like \textbf{Amazon or the Apple App Store, but specifically designed for Artificial Intelligence (AI) models, powered by Blockchain}.

Here is a simple explanation of how each part works:

\subsection{1. What is an AI Model in Simple Words?}
An AI model is a trained file (like a digital brain or a mathematical formula) that can predict things. For example:
\begin{itemize}[leftmargin=1.5em]
    \item Predicting how much crop a farm will produce based on rainfall and soil.
    \item Detecting if a credit card transaction is fraudulent.
    \item Automatically sorting candidate resumes by tech skills.
\end{itemize}
These models take days or weeks of hard work and expensive computing power to train.

\subsection{2. The 3 User Roles in ModelProof}
Anyone using the website can switch between three main roles:
\begin{enumerate}[label=\textbf{(\alph*)}]
    \item \textbf{The Creator (Seller):} An AI developer who uploads their trained model file, sets a price in Ethereum (ETH), and receives payments directly.
    \item \textbf{The Buyer (Customer):} A software developer or company who browses the models, tests them with live inputs, and buys access or full ownership.
    \item \textbf{The Admin (Supervisor):} Monitors total volume, protects the marketplace, and can hit an emergency ``Pause'' button if any problem occurs.
\end{enumerate}

\subsection{3. How Does a Purchase Work? (The Dual-Tier Choice)}
When a buyer finds a model they want, they have two simple choices:
\begin{itemize}[leftmargin=1.5em]
    \item \textbf{Choice 1: 30-Day License (Standard Price, e.g., 0.03 ETH):} \\
    The buyer gets access to run predictions online through the website and an API key for 30 days. Perfect for testing or short-term projects. After 30 days, access automatically stops.
    \item \textbf{Choice 2: Buy the Whole Model (3x Price, e.g., 0.09 ETH):} \\
    The buyer pays extra to get **permanent lifetime ownership**. They can directly download the actual model file (\texttt{.joblib}) to their own computer, run it offline forever, and receive an official **ModelProof Verified\texttrademark** ownership certificate on the blockchain.
\end{itemize}

\subsection{4. Fair Money Split: 98\% to Creator, 2\% to Platform}
In traditional app stores, companies like Apple or Google take up to 30\% of every sale. In ModelProof:
\begin{equation*}
    \text{Creator receives } \mathbf{98\%} \quad \mid \quad \text{Platform fee is only } \mathbf{2\%}
\end{equation*}
This payment happens **automatically and instantly** through a smart contract when the buyer approves the transaction in their MetaMask wallet.

\subsection{5. The Verification Portal (Catching Fake or Modified Files)}
If someone downloads a model file from the internet, how do they know it hasn't been altered or injected with a virus?
\begin{itemize}[leftmargin=1.5em]
    \item They drag and drop the file into ModelProof's \texttt{/verify} page.
    \item The platform instantly calculates the file's unique digital fingerprint (SHA-256 hash) and compares it with the immutable record on Ethereum.
    \item \textbf{Green Screen:} It matches 100\%! Shows the official green **``ModelProof Verified\texttrademark''** seal.
    \item \textbf{Red Screen:} Hash mismatch! Warns the user that the file was altered, corrupted, or does not originate from the original creator.
\end{itemize}

\subsection{6. The Emergency Circuit Breaker (Safety Mechanism)}
If an issue or malicious activity is discovered, the Admin can toggle **Emergency Pause**. This instantly freezes all purchasing, licensing, and model downloads across the smart contract, backend server, and frontend user interface until it is safely unpaused.

\section{Solidity Smart Contract Architecture (\texttt{ModelProof.sol})}

The smart contract is written in Solidity \texttt{\^{}0.8.24} and implements OpenZeppelin security contracts: \texttt{Ownable}, \texttt{ReentrancyGuard}, and \texttt{Pausable}.

\subsection{Key Data Structures}
\begin{lstlisting}[language=Solidity, caption={Data Structures in ModelProof.sol}]
struct Model {
    uint256 modelId;
    address creator;
    string name;
    string description;
    string framework;
    string version;
    bytes32 modelHash; // SHA-256 Cryptographic Fingerprint
    string ipfsCid;    // IPFS Storage Reference
    uint256 licensePrice;
    uint256 createdAt;
    bool active;
}

struct License {
    uint256 licenseId;
    uint256 modelId;
    address licensee;
    uint256 issuedAt;
    uint256 expiry;
    bool active;
}
\end{lstlisting}

\subsection{Core Function Interfaces}
\begin{itemize}[leftmargin=1.5em]
    \item \texttt{registerModel(name, desc, framework, version, hash, cid, price)}: Anchors new model fingerprint to Ethereum.
    \item \texttt{purchaseLicense(modelId)}: Standard 30-day license purchase; splits 98\% creator / 2\% platform treasury.
    \item \texttt{purchaseModelOwnership(modelId)}: Full buyout for 3x price; marks \texttt{hasModelOwnership[modelId][buyer] = true} with 100-year lifetime validity.
    \item \texttt{isModelProofVerified(modelId, hash, buyer)}: View helper verifying hash integrity and buyer ownership status.
    \item \texttt{pause() / unpause()}: Emergency circuit breaker freezing operations during detected exploits.
\end{itemize}

\section{MetaMask Integration \& Web3 Settlement}

The client connects to user wallets using the \textbf{Viem} Web3 library:
\begin{enumerate}[label=\textbf{\arabic*.}]
    \item \textbf{Wallet Onboarding:} Detects \texttt{window.ethereum} provider and requests authorization via \texttt{eth\_requestAccounts}.
    \item \textbf{Network Enforcement:} Enforces Ethereum Sepolia Testnet (Chain ID \texttt{11155111}).
    \item \textbf{Role Switching:} Listens to \texttt{accountsChanged} events in MetaMask to switch dynamically between **Buyer**, **Creator**, and **Admin** permissions in the UI.
    \item \textbf{Transaction Signing:} Prompts MetaMask for explicit signature confirmation and transparent gas fee estimations.
\end{enumerate}
